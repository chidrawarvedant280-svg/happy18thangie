## What’s Inside
- `index.html` — The complete birthday celebration web app (Landing, Goofy Cupcake Factory, Visual Studio Coding Challenge, Rapunzel’s Frying Pan & Lantern Chaos, Memory Board Timeline, and Finale).
- `404.html` — Custom sky-blue redirect page.
- `manifest.webmanifest` — Lets you add the site to your phone’s home screen like an app.
- `assets/` — Custom browser tab icon (`favicon.svg`) and link-preview card (`og-preview.png`).
- `.nojekyll` — Ensures GitHub Pages serves everything cleanly as static files.
